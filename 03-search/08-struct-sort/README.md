# 08. Сортировка массивов структур (`StructSort`)

| Файл | Назначение |
|---|---|
| `task1_fio.c` | ручная сортировка четырёх ФИО по сложному ключу и двоичный поиск |
| `task2_phonebook.c` | телефонный справочник: сортировка включением и быстрый двоичный поиск |

**Сборка:**

```bash
clang task2_phonebook.c -o task2_phonebook -lm && ./task2_phonebook
```

## Задание

1. Для набора из четырёх ФИО выполнить вручную сортировку по сложному ключу «фамилия + имя».
2. Написать сортировку телефонного справочника по сложному ключу любым методом, кроме пузырькового; запись должна содержать минимум четыре поля.
3. Реализовать функцию сравнения абонентов по ключу минимум из двух полей записи.
4. Вывести на экран исходный и отсортированный справочник.
5. Предусмотреть смену ключа и направления сортировки через функцию сравнения.
6\*. Реализовать быстрый двоичный поиск по старшей части сложного ключа.

## Псевдокод

**Сравнение по сложному ключу:**

```
function Less(x, y)
    IF x.Фамилия < y.Фамилия THEN Less ← истина
    ELSEIF x.Фамилия > y.Фамилия THEN Less ← ложь
    ELSE Less ← (x.Имя < y.Имя)
    FI
```

**Сортировка включением по этому ключу:**

```
DO i = 2 … n
    t ← aᵢ,  j ← i−1
    DO пока j > 0 и Less(t, aⱼ)
        aⱼ₊₁ ← aⱼ,  j ← j−1
    OD
    aⱼ₊₁ ← t
OD
```

## Трудоёмкость

| Операция | Оценка |
|---|---|
| Сортировка включением | `C = O(n²)`, `M = O(n²)` |
| Двоичный поиск по старшей части ключа | `C = O(log n)` |

Направление сортировки меняется заменой `<` на `>` внутри функции сравнения; пересылка записи — обычное побитовое копирование, переопределять её не нужно.

**Зависимость от упорядоченности:** как у метода прямого включения — сильная.
**Устойчивость:** устойчивая.

## Проверка правильности

- Справочник печатается до и после сортировки.
- Поиск проверяется на существующей фамилии (выводятся все однофамильцы) и на отсутствующей.
