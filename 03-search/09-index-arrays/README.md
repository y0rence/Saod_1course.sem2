# 09. Индексация массивов (`IndexArrays`)

| Файл | Назначение |
|---|---|
| `index_arrays.c` | четыре индексных массива для 12 символов ФИО и справочник с двумя индексами |

**Сборка:**

```bash
clang index_arrays.c -o index_arrays -lm && ./index_arrays
```

## Задание

1. Для 12 первых символов ФИО построить вручную четыре индексных массива: по возрастанию, по убыванию, только согласные по возрастанию, только гласные по убыванию.
2. Написать сортировку телефонного справочника с использованием индексации; запись содержит четыре поля.
3. Создать два индексных массива для упорядочивания по двум разным полям любым методом, кроме пузырькового.
4. Вывести справочник, отсортированный по двум разным полям, через построенные индексы.
5\*. Реализовать быстрый двоичный поиск по двум разным ключам с использованием индексов.

## Псевдокод

```
B ← (1, 2, …, n)
DO i = 1 … n−1
    DO j = n … i+1
        IF a[bⱼ] < a[bⱼ₋₁] THEN bⱼ ↔ bⱼ₋₁
    OD
OD
```

Сортируется только индексный массив `B`, сами записи не перемещаются. Последовательность `A[B[1]], A[B[2]], …` читается как упорядоченная.

## Трудоёмкость

| Операция | Оценка |
|---|---|
| Построение индекса | как у выбранного метода сортировки, здесь `O(n²)` |
| Доступ по индексу | `O(1)` |
| Двоичный поиск через индекс | `O(log n)` |
| Дополнительная память | `n` чисел (или указателей) на каждый индекс |

**Преимущества индексации:**
1. Можно держать **несколько индексов** для одного массива и переключаться между ними без пересортировки.
2. Большие записи **не копируются** — перемещаются только номера.
3. **Фильтрация:** в индекс включаются только записи, удовлетворяющие условию.

Если вместо номеров хранить адреса, получается индексация через массив указателей: данные могут лежать где угодно в динамической памяти.

**Зависимость от упорядоченности:** определяется методом, которым сортируется индекс.

## Проверка правильности

- Индексы печатаются вместе с символами, на которые они указывают.
- Справочник выводится по каждому индексу отдельно, поиск проверяется по фамилии и по телефону (в том числе для двух записей с одинаковым номером).
