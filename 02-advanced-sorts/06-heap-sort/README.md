## Псевдокод

**Построение (L, R)-пирамиды** — просеивание нового элемента `a_L`:

```
x ← a_L,  i ← L
DO
    j ← 2i
    IF j > R              THEN выход
    IF j < R и aⱼ₊₁ ≤ aⱼ  THEN j ← j+1
    IF x ≤ aⱼ             THEN выход
    aᵢ ← aⱼ,  i ← j
OD
aᵢ ← x
```

**Сортировка:**

```
L ← ⌊n/2⌋
DO пока L > 0:  <построение (L, n)-пирамиды>,  L ← L−1  OD
R ← n
DO пока R > 1
    a₁ ↔ a_R,  R ← R−1
    <построение (1, R)-пирамиды>
OD
```

Последовательность `aᵢ … aₖ` называется пирамидой, если `aⱼ ≤ min(a₂ⱼ, a₂ⱼ₊₁)`. Первый элемент пирамиды — минимум, а правая половина любого массива уже является пирамидой.

## Трудоёмкость

| Этап | Сравнения | Пересылки |
|---|---|---|
| Построение `(L, R)` | `C ≤ 2·log(R/L)` | `M ≤ log(R/L) + 2` |
| Вся сортировка | `C ≤ 2n·log n + n + 2` | `M ≤ n·log n + 6.5n − 4` |

Итог: `M + C ≤ 3n·log n + 7.5n − 2`, то есть `O(n log n)` в любом случае, без дополнительной памяти.

**Зависимость от упорядоченности: нет.** Значения `Мф + Сф` на убывающем, случайном и возрастающем массивах отличаются незначительно.

**Устойчивость:** неустойчивая.

> Пирамида из пособия минимальная (min-heap), поэтому результат получается **упорядоченным по убыванию**.

## Проверка правильности

- **Контрольная сумма.** Сумма элементов до и после сортировки должна совпадать: иначе элементы потерялись.
- **Число серий.** Серия — неубывающий участок. У массива, упорядоченного по возрастанию, ровно одна серия.
- **Счётчики `Мф` и `Сф`** сравниваются с теоретическими оценками на убывающем, случайном и возрастающем массивах.
