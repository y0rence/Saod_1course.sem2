# 05. Метод Шелла (`ShellSort`)

| Файл | Назначение |
|---|---|
| `shell_sort.c` | ShellSort с разными рядами шагов, квадратичные методы, таблицы и график |
| `shell_sort_v2.c` | вторая версия той же работы без графика |

**Сборка:**

```bash
clang -I/opt/homebrew/include shell_sort.c -o shell_sort \
    -L/opt/homebrew/lib -lcsfml-graphics -lcsfml-window -lcsfml-system -lm && ./shell_sort
```

## Задание

1. Для 8 первых символов ФИО выполнить сортировку методом Шелла вручную с шагами `h = 2, 1`.
2. Написать сортировку массива целых чисел методом Шелла; проверить контрольной суммой и числом серий; считать `Мф` и `Сф`.
3. Исследовать трудоёмкость для `n = 100 … 500`, шаги взять по формуле Д. Кнута, сравнить с методом прямого включения.
4\*. Исследовать зависимость трудоёмкости от выбора последовательности шагов и подтвердить (или опровергнуть) рекомендацию Кнута.
5\*. Построить графики `Мф + Сф` для четырёх квадратичных методов и метода Шелла.

## Псевдокод

```
DO k = hₘ, hₘ₋₁ … 1
    DO i = k+1 … n
        t ← aᵢ,  j ← i−k
        DO пока j > 0 и t < aⱼ
            aⱼ₊ₖ ← aⱼ,  j ← j−k
        OD
        aⱼ₊ₖ ← t
    OD
OD
```

**Шаги Кнута:** `h₁ = 1`, `hᵢ = 2·hᵢ₋₁ + 1`, число шагов `m = ⌊log₂ n⌋ − 1` (ряд 1, 3, 7, 15, 31 …).
Последний шаг `h₁ = 1` — это обычное прямое включение, оно и гарантирует полную упорядоченность.

## Трудоёмкость

| Ряд шагов | Средняя трудоёмкость |
|---|---|
| Кнута (`2h + 1`) | `≈ O(n¹·²)` |
| Половинное деление (`n/2, n/4 …`) | заметно хуже ряда Кнута |
| Токуды | близко к ряду Кнута |

**Зависимость от упорядоченности: слабая.** Упорядоченный массив обрабатывается быстрее, потому что в основе лежит прямое включение.

**Устойчивость:** неустойчивая.

## Проверка правильности

- **Контрольная сумма.** Сумма элементов до и после сортировки должна совпадать: иначе элементы потерялись.
- **Число серий.** Серия — неубывающий участок. У массива, упорядоченного по возрастанию, ровно одна серия.
- **Счётчики `Мф` и `Сф`** сравниваются с теоретическими оценками на убывающем, случайном и возрастающем массивах.
