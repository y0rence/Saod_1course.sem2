# 14. Хеширование: метод прямого связывания (`HashChaining`)

| Файл | Назначение |
|---|---|
| `hash_chaining.cpp` | хеш-таблица со списками, подсчёт коллизий для разных размеров таблицы |

**Сборка:**

```bash
clang++ -std=c++17 hash_chaining.cpp -o hash_chaining && ./hash_chaining
```

## Задание

1. Для 12 первых неповторяющихся символов ФИО выполнить хеширование вручную методом прямого связывания при размере таблицы 5.
2. Реализовать метод прямого связывания; подобрать размер таблицы так, чтобы поиск был быстрее двоичного; считать `Кф` и вывести построенные списки.
3. Исследовать зависимость количества коллизий от размера таблицы: взять десять простых чисел от 11 до 101 и построить таблицу.
4\*. Организовать поиск элемента с заданным ключом, выводя номер списка и позицию элемента в нём.

## Псевдокод

**Хеш-функция для строки** (строка рассматривается как число в 256-ичной системе):

```
h ← 0
DO i = 1 … t:  h ← (h·256 + Sᵢ) mod m  OD
```

**Включение и поиск:**

```
Включение:  i ← H(k); <добавить k в конец i-го списка>
Поиск:      i ← H(k); <последовательный просмотр i-го списка>
```

Хеш-функция `H: K → A` отображает множество ключей в индексы таблицы, причём `|K| ≫ |A|`. Совпадение `H(kᵢ) = H(kⱼ)` при `kᵢ ≠ kⱼ` называется **коллизией**. Размер `m` рекомендуется брать простым числом (метод деления).

## Трудоёмкость

| Величина | Оценка |
|---|---|
| Средняя длина списка | `n / m` |
| Среднее число сравнений при поиске | `C_ср = n / 2m` |
| Дополнительная память | `m + n` указателей |
| Худший случай (все ключи в один список) | `O(n)` |

При `n < m` в большинстве случаев достаточно одного сравнения. Метод прямого связывания выгоднее дерева поиска, когда `n / 2m < log n`, то есть `m > n / (2·log n)`.

**Зависимость от порядка добавления ключей: нет**, важно лишь качество хеш-функции.

**Хорошая хеш-функция** быстро вычисляется и равномерно распределяет ключи по всему диапазону индексов.

## Проверка правильности

- Построенные списки выводятся на экран целиком.
- Количество коллизий `Кф` считается при вставке и сравнивается для десяти простых размеров таблицы.
- Поиск проверяется на существующем ключе: выводится номер списка и позиция в нём.
