| Файл | Назначение |

| `hash_open_addressing.cpp` | линейные и квадратичные пробы, цепочки для сравнения, поиск |

**Сборка:**

```bash
clang++ -std=c++17 hash_open_addressing.cpp -o hash_open_addressing && ./hash_open_addressing
```

## Задание

1. Для 12 первых неповторяющихся символов ФИО выполнить хеширование вручную линейными и квадратичными пробами при размере таблицы 11.
2. Реализовать открытую адресацию двумя способами разрешения коллизий (линейные и квадратичные пробы), считать `Кф` и вывести обе таблицы.
3. Сравнить количество коллизий при линейных и квадратичных пробах для десяти простых размеров таблицы от 11 до 101.
4\*. Организовать поиск элемента с заданным ключом для обоих способов проб, выводя позицию элемента.

## Псевдокод

Коллизия разрешается последовательностью вторичных хеш-функций `hᵢ = (h(x) + g(i)) mod m`.

**Поиск и вставка элемента при квадратичных пробах** (`d₀ = 1`, `hᵢ₊₁ = hᵢ + dᵢ`, `dᵢ₊₁ = dᵢ + 2`):

```
h ← x mod m,  d ← 1
DO
    IF a_h = x  THEN элемент найден, выход
    IF a_h = 0  THEN ячейка пуста: a_h ← x, выход
    IF d ≥ m    THEN переполнение таблицы, выход
    h ← h + d;  IF h ≥ m THEN h ← h − m FI
    d ← d + 2
OD
```

Для поиска используется тот же цикл без присваивания `a_h ← x`. Рекуррентная формула избавляет от умножения и деления: остаток заменён вычитанием.

## Трудоёмкость

| Метод | `g(i)` | Достоинство | Недостаток |
|---|:---:|---|---|
| Линейные пробы | `i` | просматривается вся таблица | ключи группируются в кластеры вокруг первичных |
| Квадратичные пробы | `i²` | хорошее рассеивание ключей | таблица используется не полностью |

**Утверждение.** Если `m` — простое число, при квадратичных пробах просматривается не меньше половины хеш-таблицы.

| Величина | Оценка |
|---|---|
| Поиск при незаполненной таблице | `O(1)` |
| Худший случай | `O(m)` |
| Дополнительная память | только сама таблица из `m` ячеек, списков нет |

**Зависимость от порядка добавления ключей: нет**; на практике `m/2` вторичных проб встречаются крайне редко, в основном при почти заполненной таблице.

## Проверка правильности

- Обе заполненные хеш-таблицы выводятся по ячейкам.
- Количество коллизий `Кф` сравнивается для цепочек, линейных и квадратичных проб при десяти размерах таблицы.
- Поиск печатает всю последовательность просмотренных позиций.
