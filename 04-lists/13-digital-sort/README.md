# 13. Цифровая сортировка (`DigitalSort`)

| Файл | Назначение |
|---|---|
| `digital_sort.cpp` | цифровая сортировка списка по байтам ключа, сортировка фамилий, график |

**Сборка:**

```bash
clang++ -std=c++17 -I/opt/homebrew/include digital_sort.cpp -o digital_sort \
    -L/opt/homebrew/lib -lsfml-graphics -lsfml-window -lsfml-system && ./digital_sort
```

## Задание

1. Для 12 трёхзначных чисел в 6-ичной системе счисления выполнить цифровую сортировку вручную.
2. Написать цифровую сортировку списка целых чисел по возрастанию; проверить контрольной суммой и числом серий; считать `Мф` и сравнить с теоретической оценкой.
3. Применить DigitalSort к спискам двухбайтовых и четырёхбайтовых чисел в прямом и обратном порядке.
4. Сравнить работу метода на убывающих, возрастающих и случайных списках, составить таблицу для `N = 100 … 500`.
5\*. Построить графики трудоёмкости для HeapSort, QuickSort, MergeSort и DigitalSort.
6\*. Применить DigitalSort для упорядочивания списка фамилий по возрастанию и убыванию.
7\*. Определить, при каком количестве байтов в числах DigitalSort начинает работать медленнее QuickSort.

## Псевдокод

```
DO j = L, L−1 … 1
    DO i = 0 … m−1:  Qᵢ.Tail ← @Qᵢ.Head  OD
    p ← S
    DO пока p ≠ NIL
        d ← p→Digit[j]
        Q_d.Tail→Next ← p;  Q_d.Tail ← p;  p ← p→Next
    OD
    p ← @S
    DO i = 0 … m−1
        IF Qᵢ.Tail ≠ @Qᵢ.Head THEN p→Next ← Qᵢ.Head;  p ← Qᵢ.Tail FI
    OD
    p→Next ← NIL
OD
```

Числа раскладываются по `m` очередям сначала по последней цифре, затем очереди склеиваются, и всё повторяется для следующей цифры. Для произвольных данных цифрой считается **байт** ключа, поэтому `m = 256`, а байты берутся через массив `Digit`, наложенный на поле данных.

## Трудоёмкость

| Величина | Оценка |
|---|---|
| Пересылки | `M < const · L · (m + n)` |
| Асимптотика | `O(n)` при фиксированных `L` и `m` |
| Сравнения | отсутствуют |
| Дополнительная память | `m` очередей |

**Зависимость от упорядоченности: нет** — выполняется ровно `L` проходов по списку независимо от данных.

**Устойчивость:** устойчивая.

**Сортировка по убыванию:** очереди склеиваются в обратном порядке (`m−1 … 0`).

> Метод обходит нижнюю границу `n log n`, потому что не сравнивает элементы. Но при большой длине ключа `L` он проигрывает обычным сортировкам и применим, только если ключ можно представить последовательностью цифр.

## Проверка правильности

- Контрольная сумма списка до и после сортировки.
- Число серий после сортировки равно `1`.
- Количество элементов в списке сохраняется.
