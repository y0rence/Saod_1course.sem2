# 11. Линейные списки: стек и очередь (`StackQueue`)

| Файл | Назначение |
|---|---|
| `lists.cpp` | создание стека и очереди, контрольная сумма, серии, рекурсивная печать, удаление |

**Сборка:**

```bash
clang++ -std=c++17 lists.cpp -o lists && ./lists
```

## Задание

1. Написать функции создания стека: заполнение возрастающими, убывающими и случайными числами.
2. Написать функции создания очереди: заполнение возрастающими, убывающими и случайными числами.
3. Написать функции работы со списком: печать элементов, подсчёт контрольной суммы, подсчёт числа серий.
4\*. Написать функцию удаления всех элементов из списка.
5\*. Написать рекурсивную функцию печати элементов в прямом и обратном порядке.

## Псевдокод

**Добавление в стек и удаление из него:**

```
p→Next ← Head;  Head ← p
p ← Head;  Head ← p→Next;  <освободить память по адресу p>
```

**Добавление в очередь:**

```
p→Next ← NIL
IF Head ≠ NIL THEN Tail→Next ← p ELSE Head ← p FI
Tail ← p
```

**Перемещение элемента из начала списка в конец очереди:**

```
Queue.Tail→Next ← List
Queue.Tail ← List
List ← List→Next
```

**Рекурсивная печать:**

```
Печать(p):     IF p ≠ NIL THEN вывод p→Data; Печать(p→Next) FI
ПечатьОбр(p):  IF p ≠ NIL THEN ПечатьОбр(p→Next); вывод p→Data FI
```

## Трудоёмкость

| Операция | Оценка |
|---|:---:|
| Добавление в стек / очередь | `O(1)` |
| Удаление из начала | `O(1)` |
| Печать, контрольная сумма, число серий | `O(n)` |
| Удаление всего списка | `O(n)` |
| Рекурсивная печать | `O(n)` времени и `O(n)` кадров стека |

Стек работает по принципу LIFO (новый элемент в начало), очередь — FIFO (новый элемент в конец, удаление из начала). Для очереди нужен дополнительный указатель `Tail`.

Доступ к элементам списка только последовательный, поэтому методы сортировки массивов для списков не годятся.

## Проверка правильности

- Контрольная сумма списка.
- Число серий: у возрастающего списка ровно одна серия, у убывающего — `n`.
- После удаления список должен стать пустым.
