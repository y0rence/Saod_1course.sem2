## Задание

1. Для 12 первых символов ФИО выполнить сортировку прямого слияния вручную.
2. Написать расщепление списка (`n ≥ 20`) на два списка через один элемент и вывести оба списка с количеством элементов.
3. Написать слияние серий; вывести число серий и контрольную сумму, считать `Сф` и `Мф` (перемещения из стека в очередь).
4. Написать сортировку списка методом прямого слияния с подсчётом `Сф` и `Мф`.
5. Сравнить работу метода на убывающих, возрастающих и случайных списках, составить таблицу для `N = 100 … 500`.
6\*. Построить графики зависимости `Мф + Сф` от размера для HeapSort, QuickSort и MergeSort.

## Псевдокод

**Расщепление списка:**

```
a ← S,  b ← S→Next,  n ← 1
k ← a,  p ← b
DO пока p ≠ NIL
    n ← n+1
    k→Next ← p→Next
    k ← p,  p ← p→Next
OD
```

**Слияние q-серии из `a` и r-серии из `b` в очередь `c`:**

```
DO пока q ≠ 0 и r ≠ 0
    IF a→Data ≤ b→Data THEN <переместить элемент из a в c>, q ← q−1
                       ELSE <переместить элемент из b в c>, r ← r−1
    FI
OD
DO пока q > 0: <переместить из a в c>, q ← q−1 OD
DO пока r > 0: <переместить из b в c>, r ← r−1 OD
```

**Сортировка:**

```
<Расщепление(S, a, b, n)>
p ← 1
DO пока p < n
    <инициализация очередей c₀, c₁>;  i ← 0;  m ← n
    DO пока m > 0
        q ← min(p, m);  m ← m − q
        r ← min(p, m);  m ← m − r
        <Слияние(a, q, b, r, cᵢ)>;  i ← 1 − i
    OD
    a ← c₀.Head,  b ← c₁.Head,  p ← 2p
OD
c₀.Tail→Next ← NIL;  S ← c₀.Head
```

## Трудоёмкость

| Величина | Оценка |
|---|---|
| Слияние двух серий | `min(q, r) ≤ C ≤ q + r − 1`, `M = q + r` |
| Сравнения | `C < n·⌈log₂ n⌉` |
| Пересылки | `M = n·⌈log₂ n⌉ + n` (дополнительные `n` — расщепление) |
| Асимптотика | `O(n log n)` |

**Зависимость от упорядоченности:** `M` не зависит, `C` зависит слабо — на упорядоченных данных слияние заканчивается раньше.

**Устойчивость:** устойчивая.

**Память:** при работе со списками дополнительная память не нужна, для массивов понадобился бы второй массив такого же размера.

## Проверка правильности

- Контрольная сумма списка до и после сортировки.
- Число серий после сортировки равно `1`.
- Количество элементов после расщепления и слияния совпадает с исходным.
