# 02. Пузырьковая сортировка (`BubbleSort`)

| Файл | Назначение |
|---|---|
| `bubble_sort.c` | BubbleSort, SelectSort для сравнения, таблица трудоёмкости |

**Сборка:**

```bash
clang bubble_sort.c -o bubble_sort -lm && ./bubble_sort
```

## Задание

1. Для 8 первых символов ФИО выполнить пузырьковую сортировку вручную.
2. Написать пузырьковую сортировку массива целых чисел по возрастанию; проверить контрольной суммой и числом серий; считать `Мф` и `Сф`.
3. Сравнить работу метода на убывающих, возрастающих и случайных массивах по сумме `Мф + Сф`.
4. Составить таблицу трудоёмкости для `N = 100 … 500`.
5\*. Построить графики `Мф + Сф` для прямого выбора и пузырьковой сортировки.

## Псевдокод

```
DO i = 1 … n−1
    DO j = n, n−1 … i+1
        IF aⱼ < aⱼ₋₁ THEN aⱼ ↔ aⱼ₋₁
    OD
OD
```

## Трудоёмкость

| Величина | Минимум (возрастающий) | Максимум (убывающий) |
|---|:---:|:---:|
| Сравнения `C` | `(n² − n)/2` | `(n² − n)/2` |
| Пересылки `M` | `0` | `3(n² − n)/2` |

Суммарная теоретическая оценка `M + C = 2(n² − n)` для худшего случая, асимптотика `O(n²)`.

**Зависимость от упорядоченности: только через `M`.** Число сравнений постоянно, число пересылок меняется от нуля до максимума.

**Устойчивость:** устойчивая.

## Проверка правильности

- **Контрольная сумма.** Сумма элементов до и после сортировки должна совпадать: иначе элементы потерялись.
- **Число серий.** Серия — неубывающий участок. У массива, упорядоченного по возрастанию, ровно одна серия.
- **Счётчики `Мф` и `Сф`** сравниваются с теоретическими оценками на убывающем, случайном и возрастающем массивах.
