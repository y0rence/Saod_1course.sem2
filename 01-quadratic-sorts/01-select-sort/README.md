# 01. Сортировка прямого выбора (`SelectSort`)

| Файл | Назначение |
|---|---|
| `select_sort.c` | заполнение массивов, SelectSort, улучшенный SelectSort, таблица трудоёмкости |

**Сборка:**

```bash
clang select_sort.c -o select_sort -lm && ./select_sort
```

## Задание

1. Для 8 первых символов ФИО выполнить сортировку прямого выбора вручную и использовать этот пример как тест.
2. Написать сортировку массива целых чисел по возрастанию методом прямого выбора; проверить контрольной суммой и числом серий; считать `Мф` и `Сф` и сравнить с теоретическими `M` и `C`.
3. Исследовать метод на убывающих, возрастающих и случайных массивах и сделать вывод о зависимости от исходной упорядоченности.
4\*. Предложить способ устранения фиктивных перестановок и оценить его влияние на `Мф` и `Сф`.
5. Составить таблицу трудоёмкости для `N = 10` и `N = 100`.
5\*. Построить график зависимости `Мф + Сф` от размера массива.

## Псевдокод

```
DO i = 1 … n−1
    k ← индекс минимума среди aᵢ … aₙ
    aᵢ ↔ aₖ
OD
```

Улучшение: обмен выполняется только при `k ≠ i`, что убирает фиктивные перестановки.

## Трудоёмкость

| Величина | Значение |
|---|---|
| Сравнения | `C = (n² − n) / 2` |
| Пересылки | `M = 3(n − 1)` |
| Асимптотика | `O(n²)` |

**Зависимость от упорядоченности: нет.** `M` и `C` одинаковы на убывающем, случайном и возрастающем массивах.
В улучшенной версии на упорядоченном массиве `M = 0`, но число сравнений не меняется.

**Устойчивость:** неустойчивая.

## Проверка правильности

- **Контрольная сумма.** Сумма элементов до и после сортировки должна совпадать: иначе элементы потерялись.
- **Число серий.** Серия — неубывающий участок. У массива, упорядоченного по возрастанию, ровно одна серия.
- **Счётчики `Мф` и `Сф`** сравниваются с теоретическими оценками на убывающем, случайном и возрастающем массивах.
