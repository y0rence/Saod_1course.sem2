# 04. Сортировка прямого включения (`InsertSort`)

| Файл | Назначение |
|---|---|
| `insert_sort.c` | InsertSort, SelectSort, BubbleSort, ShakerSort, таблицы и график (CSFML) |

**Сборка:**

```bash
clang -I/opt/homebrew/include insert_sort.c -o insert_sort \
    -L/opt/homebrew/lib -lcsfml-graphics -lcsfml-window -lcsfml-system -lm && ./insert_sort
```

## Задание

1. Для 8 первых символов ФИО выполнить сортировку прямого включения вручную.
2. Написать сортировку массива целых чисел по возрастанию методом прямого включения; считать `Мф` и `Сф` и сравнить с теоретическими оценками.
3. Сравнить работу метода на убывающих, возрастающих и случайных массивах, составить таблицу для `N = 100 … 500`.
4. Сравнить четыре квадратичных метода (SelectSort, BubbleSort, ShakerSort, InsertSort) на случайных массивах.
5\*. Построить в одной системе координат графики `Мф + Сф` для четырёх квадратичных методов.

## Псевдокод

```
DO i = 2 … n
    t ← aᵢ,  j ← i−1
    DO пока j > 0 и t < aⱼ
        aⱼ₊₁ ← aⱼ,  j ← j−1
    OD
    aⱼ₊₁ ← t
OD
```

## Трудоёмкость

| Величина | Минимум (возрастающий) | Максимум (убывающий) |
|---|:---:|:---:|
| Сравнения `C` | `n − 1` | `(n² − n)/2` |
| Пересылки `M` | `2(n − 1)` | `(n² − n)/2 + 2n − 2` |

Средняя трудоёмкость `O(n²)`.

**Зависимость от упорядоченности: сильная.** На почти упорядоченном массиве метод работает почти линейно — именно поэтому он лежит в основе метода Шелла.

**Устойчивость:** устойчивая.

## Проверка правильности

- **Контрольная сумма.** Сумма элементов до и после сортировки должна совпадать: иначе элементы потерялись.
- **Число серий.** Серия — неубывающий участок. У массива, упорядоченного по возрастанию, ровно одна серия.
- **Счётчики `Мф` и `Сф`** сравниваются с теоретическими оценками на убывающем, случайном и возрастающем массивах.
